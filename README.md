SHADOW LANE is a top-down stealth game starring Miso the thief. Sneak through 3 museum floors past guards with vision cones, using crates and bushes for cover, grab the gems, and reach the glowing EXIT. You have 3 lives, and WebAudio sound effects keep every close call tense.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in your browser
```
